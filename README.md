# EU AI Regulation Monitor

An AI-powered platform for automatically monitoring, collecting, analyzing, and tracking updates to EU regulations related to Smart TV, DVB, CI+, HbbTV, satellite, and broadcasting.

## Features

- Crawl official regulation websites
- AI-powered regulation analysis
- Structured JSON output
- Regulation change detection
- Multi-source monitoring (planned)

## Tech Stack

- Python 3.11
- OpenAI API
- Firecrawl
- GitHub
